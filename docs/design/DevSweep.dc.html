Interaction rules
Checking a node applies to all its children; parents roll up to mixed. Blocked and info-only rows are skipped by “select all” and by parent propagation.
Right-click a row: Reveal in Finder · Select all safe · Copy path · Copy command. Info-only rows swap the first two for “Copy commands”.
Modules are the depth-0 rows of the tree, so a whole module can be selected with one checkbox. Right-click a module: Hide module · Rescan module · Collapse others.
Blocked rows keep the checkbox visible but disabled, with the reason in .help(); the tree never hides what it can't delete.
Delete mode is remembered per launch; the destructive tint appears only on the footer button, the permanent segment, and the confirmation sheet.
